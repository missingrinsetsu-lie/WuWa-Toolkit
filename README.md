# WuWa-Toolkit

A lightweight Shizuku-based toolkit for **Wuthering Waves** on Android — featuring an in-game overlay, real-time FPS & RAM monitor, and `Engine.ini` config editor without root.

## ✨ Features
- **No Root Required** — Powered by Shizuku.
- **In-Game Overlay** — Quick floating menu while playing.
- **FPS & RAM Monitor** — Check performance and memory usage in real time.
- **Engine.ini Editor** — Easily tweak graphics and performance settings.

## 📋 Requirements
- Android device with **Wuthering Waves** installed
- **[Shizuku](https://shizuku.rikka.app/)** installed and active

## 🚀 How to Use
1. Download the latest `.apk` from the **[Releases](https://github.com/missingrinsetsu-lie/WuWa-Toolkit/releases)** page.
2. Install and start **Shizuku** (via Wireless Debugging or PC).
3. Open **WuWa-Toolkit** and grant Shizuku permission.
4. Set your `Engine.ini` or enable the overlay, then launch Wuthering Waves.

## ⚠️ Disclaimer
Use at your own risk. Make sure to back up your original `Engine.ini` before applying changes.
